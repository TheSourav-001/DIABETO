🩺 DIABETO – Smart Diabetes Tracking System

DIABETO is an intelligent diabetes management system built using JavaFX, MySQL, and IntelliJ IDEA.
It’s designed to help diabetic patients monitor, manage, and understand their health data in a smarter and more personalized way.

The system allows users to log and track their blood sugar levels, manage meals and diet plans, generate health reports, and maintain a daily routine — all from one clean, user-friendly dashboard.

🚀 Features

🔐 User Authentication (Login/Signup)

📊 Dashboard for quick health overview

🩸 Blood Sugar Tracking and analysis

🍱 Meal & Diet Management System

📄 Automated Report Generation

🕒 Daily Routine Planner

⚙️ Editable User Profile & Settings

🧩 Technology Stack
Component	Technology
Frontend/UI	JavaFX
Backend	Core Java
Database	MySQL
IDE	IntelliJ IDEA
🎯 Goal

To provide a modern, reliable, and intelligent diabetes tracking solution that empowers users to take control of their health through data-driven insights and daily monitoring.
