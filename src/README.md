# DIABETO 🩺🍽️

**DIABETO** is a Smart Diabetes Tracking System developed using **JavaFX**, **MySQL**, and **IntelliJ IDEA**. It helps diabetic patients monitor their health with real-time tracking of glucose levels, personalized alerts, and 24-hour care planning based on BMI.

---

## 💡 Features

- 🔍 Track glucose levels manually or automatically
- 🧠 Personalized diet plans based on BMI (Underweight, Normal, Overweight)
- ⏰ 24-hour care routine (exercise, hydration, medication alerts)
- 📊 GUI dashboard for daily reports
- 💾 Data stored securely in MySQL database

---

## ⚙️ Tech Stack

- **Core Language**: Java
- **Framework**: JavaFX
- **Database**: MySQL
- **IDE**: IntelliJ IDEA

---

## 🛠️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/TheSourav-001/DIABETO.git
   ```

2. Open the project in IntelliJ IDEA.

3. Make sure MySQL server is running and database credentials are correctly set in the config file.

4. Run the `Main.java` file to launch the application.
